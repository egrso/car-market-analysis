# Журнал преобразований данных

## Этап 1. Загрузка и профилирование данных

Источник: `data/raw/all_regions.csv`. Результат: `data/processed/raw_typed.parquet`. Преобразование выполнено в `notebooks/01_data_loading.ipynb`.

CSV прочитан через DuckDB в кодировке UTF-8. Сначала все колонки читаются как `VARCHAR`; пустые поля интерпретируются как `NULL`. Приведение типов через CAST:

| Колонки | Итоговый тип |
| --- | --- |
| `year`, `power` | `SMALLINT` |
| `mileage` | `INTEGER` |
| `price` | `BIGINT` |
| `date`, `parse_date` | `TIMESTAMP` |
| Остальные 12 колонок | `VARCHAR` |

Использован CAST, чтобы несовместимое значение останавливало конвертацию. Результат сохранён в Parquet со сжатием Zstandard. Все 18 колонок сохранены.

- В CSV и Parquet одинаковое количество строк: **1 294 757**.
- Количество NULL в year совпадает: **570 113**. Пропуски присутствуют в исходном CSV.
