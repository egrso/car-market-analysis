# Анализ рынка автомобилей по объявлениям Drom.ru (Kaggle)

Учебный проект по анализу данных об автомобилях на основе датасета с Kaggle. Исследование структуры предложения, связи цены с характеристиками автомобиля и региональных различий после проверки и очистки исходных данных.

Используется Python 3.14.6

**Статус:** Завершён этап загрузки и профилирования данных (этап 1).

## Данные

Основной источник: файл `all_regions.csv` с объявлениями Drom.ru (2023), датасет с Kaggle.

| Характеристика | Значение |
| --- | --- |
| Объём исходного CSV | Около 2 ГБ |
| Количество строк | 1 294 757 |
| Количество колонок | 18 |
| Уникальные ссылки на объявления | 950 457 |
| Даты публикации в наборе | 27 марта — 21 июня 2023 года |
| Даты сбора данных | 1 мая — 21 июня 2023 года |

В данных представлены марка и модель, кузов, цвет, топливо, коробка передач, год выпуска, пробег, мощность, цена, характеристики двигателя, местоположение, описание и даты публикации и сбора объявления. Цены указаны в рублях.

Для последующего регионального анализа предусмотрен справочник [городов России](data/city.csv).

Исходный CSV и промежуточные Parquet-файлы хранятся локально.

## Что выполнено

Ноутбук [01_data_loading.ipynb](notebooks/01_data_loading.ipynb).

- Загрузка CSV через DuckDB и явное приведение числовых полей и дат к нужным типам.
- Сохранение всех 18 колонок в Parquet со сжатием Zstandard, без удаления строк.
- Контроль совпадения количества строк и пропусков года выпуска между CSV и Parquet.
- Профилирование пропусков, пустых строк, числовых полей и дат.
- Проверка полных дублей и повторных наблюдений одного объявления.
- Сравнение цен и характеристик объявлений между датами сбора.

Размер файла после преобразования сократился примерно в 9 раз: с 2 Гб до 225 Мб. Правила преобразования в [журнале обработки данных](docs/cleaning_log.md).

| Показатель | Результат |

| Полные дубли по всем 18 колонкам | 0 |
| Ссылки с несколькими наблюдениями | 213 669 |
| Строки сверх одной записи на ссылку | 344 300 — 26,59% всех строк |
| Пропуски года выпуска | 570 113 — 44,03% всех строк |
| Минимальная и максимальная цена | 270 — 150 000 000 руб. |
| Диапазон года выпуска | 1936–2023 |

Повторяющиеся ссылки относятся к наблюдениям объявлений в разные даты. У всех 213 669 таких ссылок различаются цены; у части также различаются характеристики и переходы между пропуском и известным значением.

Пропуски года выпуска присутствуют в исходном CSV. Крайние значения цены, года и мощности требуют дополнительной проверки. На текущем этапе строки сохранены.

## Запуск текущего этапа

1. Копия репозитория и установленный Python.
2. Исходный файл `all_regions.csv` в папке `data/raw/`. CSV не входит в репозиторий; для полного повторения загрузки требуется исходный датасет с Kaggle.
3. Установка зависимостей в отдельное окружение. Пример для Windows PowerShell, из корня проекта:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install duckdb pandas jupyterlab jinja2
   .\.venv\Scripts\python.exe -m jupyterlab
   ```

4. Открытие `notebooks/01_data_loading.ipynb` и выполнение ячеек по порядку.

При первом запуске Parquet создаётся автоматически. Если файл уже существует, используется готовая версия. Для пересоздания после замены CSV или изменения правил типизации в ноутбуке используется флаг `REBUILD_PARQUET = True`.

## Ограничения

- Цены относятся к предложениям продавцов; фактические цены сделок неизвестны.
- Набор охватывает ограниченный период 2023 года.
- Одна ссылка может встречаться несколько раз, поэтому количество строк не равно количеству уникальных объявлений.
- Пропуски и возможные ошибки пока не обработаны. Результаты профилирования характеризуют исходные наблюдения, а итоговые выводы о рынке появятся после очистки и анализа.
